3. WOLF (enemy) — assets/sprites/wolf/
------------------------------------------------------------
Files: wolf.png (main animation sheet, "wolfsheet1" brown-fur color
variant), wolf_howl.png (single supplementary upward-facing howl frame)
Source: "[LPC] Wolf Animation" on OpenGameArt.org
        https://opengameart.org/content/lpc-wolf-animation
Author: William.Thompsonj (submitter/commissioner)
Collaborator: Stephen "Redshrike" Challener (graphic artist)
License: CC-BY 4.0 / CC-BY 3.0 / GPL 3.0 / GPL 2.0 / OGA-BY 3.0 (submitter's
choice of any one applies; CC-BY-SA-compatible)
Attribution instructions (from the OGA page): "Attribute Stephen
'Redshrike' Challener as graphic artist and William.Thompsonj as
contributor. If reasonable link back to this page or the OGA homepage."
Note: 6 fur-color variants were offered (wolfsheet1.png .. wolfsheet6.png);
wolfsheet1.png (brown fur) was selected per the design spec ("brown fur,
no recoloring needed"). No official frame-coordinate manifest is provided
with this asset (multiple commenters on the OGA page note the same) — grid
layout was inferred visually, see the acquisition report for details.

------------------------------------------------------------
Files: lpc_terrain_atlas.png (primary — grass/farming/vegetation terrain,
